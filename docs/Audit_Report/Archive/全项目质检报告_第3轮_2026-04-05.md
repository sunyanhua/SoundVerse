| `vite.config.ts` | 缺少API代理配置 | 应添加proxy配置转发`/api`到后端 |

当前配置:
```typescript
// vite.config.ts - 当前

  plugins: [react()],
  optimizeDeps: { exclude: ['lucide-react'] },
```

预期配置:
```typescript
// vite.config.ts - 预期
export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true,
      }
    }
  }
});
```
